# 提示词存档 · 冬日限定雪绒热可可海报

## 用户实际使用的提示词（即梦平台）

```
为虚拟精品咖啡品牌「暖爪咖啡 WARM PAW」设计一张冬季限定新品商业广告海报，3:4竖版构图。

【产品主体】
一杯冒着热气的热可可，白色陶瓷杯或透明玻璃杯，表面有细腻奶泡与雪花生巧拉花，杯边放两块姜饼人和一小块金黄可颂，杯旁有肉桂棒与几颗棉花糖。食物细节真实，热气升腾感明显，具有诱人的商业产品摄影质感。

【视觉风格】
冬雪治愈系精品咖啡品牌视觉，冷调雪白背景，雾霾蓝、浅灰蓝为主色，暖黄色灯光与少量焦糖棕作为点缀。窗外可见飘雪与模糊的暖色灯光，柔和的雪地反光，真实投影，干净高级的画面，兼具生活方式摄影与可爱扁平插画元素。

【品牌角色】
加入一只原创Q版小熊猫吉祥物（请参考参考图1），圆润的头部，橘红色毛发，白色面部斑纹，深棕色环纹大尾巴，头戴米白色毛线帽、系红色围巾，双手捧着一杯热气腾腾的热可可，脸颊红润，温暖治愈的表情。角色作为辅助视觉元素，不遮挡饮品主体。

【商业排版】
顶部预留品牌Logo位置；上方安排醒目的中文标题「把冬天，暖进一杯里」；中部突出热可可与甜品主体；下方安排「冬日限定 · 雪绒热可可」及英文辅助文字「WINTER LIMITED」，底部预留产品信息与品牌落款空间。字体排版具有清晰的主次关系，画面留白充足，整体具有成熟的商业广告设计感。

高品质商业视觉、产品主体突出、统一色彩体系、精致构图、细腻纹理、干净背景、无水印、无多余装饰、无畸形产品。文字区域尽量清晰，最终文字可在设计软件中重新排版。
```

## 设计决策记录（为什么这张成立）

| 维度 | 与秋日版的系列对照 | 结果 |
|---|---|---|
| 色调 | 暖橙米白 → 冷雪白+雾霾蓝 | 对比鲜明 ✅ |
| 产品 | 肉桂苹果拿铁+苹果派 → 雪绒热可可+姜饼人+可颂 | 季节产品对应 ✅ |
| 角色 | 江天+绿围巾 → 江天+米白毛球帽+红围巾 | 同一角色冬装版 ✅ |
| 文案 | "把秋天，装进一杯里" → "把冬天，暖进一杯里" | 对仗系列感 ✅ |
| 版式 | 顶Logo→主标题→产品→副标题→底部卖点 | 结构完全一致 ✅ |
| 英文 | AUTUMN LIMITED → WINTER LIMITED | 对应 ✅ |
