## 一、视觉测试段（Day 1-12）：你怎么一步步学会"用嘴做设计"

### 1. 秋日海报 v1 你只给了 6.5 分
你看完生成的第一版秋日海报后说"还可以但不够好"。我让你具体指，你点出四个问题：
- 小熊猫像贴纸贴上去的，没有投影
- 枫叶元素太多太乱
- 文字层级弱（标题不够醒目）
- 光源不统一（江天身上的光和环境光方向反了）

→ 这就是商业设计反馈的标准动作：**不是说"不好看"，而是逐元素指出哪里不对**。

### 2. 你说"我实在不会用 PS"
这是你自己说的原话。从此定了规矩：
- 你不动手修图，只负责描述想要什么
- 所有改图由我用 AI 编辑工具代劳
- 你的核心能力是**写提示词**和**审美判断**，不是软件操作

### 3. v2 修正版怎么改的
针对 v1 四个问题逐条修：江天脚下加软投影、枫叶收敛到右上角一枝、标题放大加描边、统一暖橙侧逆光。你复看后给了好评——**这个"指出问题→逐条修复→复看验收"的循环，就是以后做 AI 视觉的基本工作流**。

## 二、Python 环境段（Day 12-20）：你说"还是没反应"的那几次

这一段你连续发了好几句"还是没反应""还是没有用""我输入的位置是不是错了"。当时我们一个个排查：

### 踩坑 1：Microsoft Store 占位符 Python
你在 VS Code 里运行脚本，系统弹出应用商店——说明 Windows 里那个"Python"是商店占位符，不是真 Python。解决：从 python.org 下载安装包，装到 `C:\Users\wjy\AppData\Local\Programs\Python\Python312\`。

### 踩坑 2：VS Code 终端直接崩
VS Code 内置终端打开就报错（ConPTY 兼容性问题），你发了报错截图。解决：改 VS Code 设置 `windowsEnableConpty: false`，强制走旧终端模式，终端恢复正常。

### 踩坑 3：pip 装 openai 装不上
网络/镜像问题，换了源才装上。

**这一段的收获**：你后来每遇到报错就直接截图发我，而不是自己瞎点——这是程序员最重要的习惯：**截图报错 + 描述现象，比自己琢磨快十倍**。

## 三、AI 文案工具段（Day 20-25）：第一次调真 API

### 1. 你给我了 API Key 和 endpoint
你提供了火山引擎的 API Key 和推理接入点 ID（两者都不写进代码，统一走环境变量；**本仓库不含任何密钥**）。第一次跑通时你说了句"挺好玩的"。

### 2. 你吐槽"软字出现次数太多"
你跑了 08 批量生成器后，反馈生成的文案里"软"字出现太多。我们判断：**这是大模型的风格偏好问题，不是脚本 bug**——以后这种情况要么改提示词约束用词，要么后处理去重。你当时说"可以下一步了"。

### 3. 你亲手改了 09 脚本的"国风"
09 工具里有个风格模板库，你自己手动加了一条"国风"风格。我帮你检查时，**发现根因不是脚本**——是 `run-batch.bat` 启动器写死了指向 08 老脚本，所以你怎么改 09 都看不到效果。改成指向 09 后，你亲手双击运行成功，国风出现在风格列表里，姜饼人拿铁生成 1/1 通过。

> 这是你第一个"自己改代码 → 自己运行 → 看到效果"的完整闭环。那天是 2026-11-05 上午。

## 四、方向决策段（Day 22，11-02）：最重要的一次对话

按原计划 Day 30（11-10）才定主方向，结果提前 8 天。过程是：

1. **你先说**："我不是太想去创建账号运营"——运营测试段直接被你划掉。
2. **我提供选项**：视觉 vs 代码 vs 都试试。
3. **你回答**："还可以 / 有但不足 / 都想试试，但代码基础我不会"。
4. **然后你说了关键一句**："我本职工作就是运营账号，你去抖音搜'小熊猫的咖啡屋'和'薛定谔的猫咖'重新评判。"
5. 我搜完发现：你本职账号有 16.6 万赞的爆款睡姿视频、3.2 万赞猫咖视频——**运营根本不需要测试，你已经有真实战绩**。
6. **你拍板**："主攻代码。"

这次对话的意义：不是随便选了个方向，而是基于"你已经有什么"做的减法——运营不用学（已经会）、视觉有作品（辅助）、代码是你缺的那块（主攻）。
