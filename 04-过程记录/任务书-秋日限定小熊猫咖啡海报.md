# 练习任务书 01：秋日限定 · 小熊猫咖啡海报

> 归档日期：2026-10-12（Day 1）
> 来源：本次 AI 商业视觉练习实战任务
> 难度：入门进阶　｜　建议用时：2–3 小时　｜　定位：作品集项目

---

## 一、模拟客户需求（Brief）

| 项 | 内容 |
|---|---|
| 客户品牌（虚拟） | 暖爪咖啡 WARM PAW |
| 品牌调性 | 可爱治愈系精品咖啡 |
| 商业目标 | 吸引年轻消费者关注秋季新品，传达温暖、治愈、有品质的形象 |
| 目标用户 | 18–30 岁，咖啡爱好者，喜欢可爱插画、爱社交分享的人群 |
| 核心产品 | 肉桂苹果拿铁 + 苹果肉桂派 |
| 核心卖点 | 秋日限定、暖香口感、治愈系视觉体验 |

## 二、需要交付的作品

### 任务 A · 主视觉海报（必做，最重要）
- 尺寸：3:4 竖版
- 主体：一杯肉桂苹果拿铁 + 苹果派
- 配色：奶油米白、焦糖橙、秋日暖棕
- 风格：商业产品摄影 + 可爱品牌插画
- 必备元素：主标题、副标题、产品名称、品牌标识

### 任务 B · 品牌吉祥物
- 专属小熊猫咖啡师，统一五官/配色/描边
- 至少 3 个动作：端咖啡、喝咖啡、制作咖啡
- 角色需可复用于海报、贴纸、包装

### 任务 C · 包装延展
- 咖啡纸杯
- 外带纸袋
- 杯套 / 贴纸
- 要求主色、字体、吉祥物与主视觉一致

## 三、起始提示词（任务 A 用）

```
为虚拟精品咖啡品牌「暖爪咖啡 WARM PAW」设计一张高品质秋季限定新品商业广告海报，3:4竖版构图。

【产品主体】
一杯精致的肉桂苹果拿铁，透明玻璃杯或质感陶瓷杯，奶泡细腻，表面有精美拉花，搭配新鲜苹果切片、肉桂棒和一块金黄酥脆的苹果肉桂派。食物细节真实，材质清晰，具有诱人的商业产品摄影质感。

【视觉风格】
治愈系精品咖啡品牌视觉，奶油米白色背景，焦糖橙、暖棕色与少量鼠尾草绿作为辅助色。柔和自然的秋日阳光，真实投影，精致的材质细节，干净高级的画面，兼具生活方式摄影与可爱扁平插画元素。

【品牌角色】
加入一只原创Q版小熊猫吉祥物，圆润的头部，橘红色毛发，白色面部斑纹，深棕色环纹大尾巴，深棕色粗描边，温暖可爱的表情。角色作为辅助视觉元素，不遮挡咖啡产品。

【商业排版】
顶部预留品牌Logo位置；上方安排醒目的中文标题「把秋天，装进一杯里」；中部突出咖啡与甜点主体；下方安排「秋日限定 · 肉桂苹果拿铁」及英文辅助文字「AUTUMN LIMITED」，底部预留产品信息与品牌落款空间。字体排版具有清晰的主次关系，画面留白充足，整体具有成熟的商业广告设计感。

高品质商业视觉、产品主体突出、统一色彩体系、精致构图、细腻纹理、干净背景、无水印、无多余装饰、无畸形产品。文字区域尽量清晰，最终文字可在设计软件中重新排版。
```

> ⚠️ 任务书自带提醒：AI 生成中文容易错字。实际工作流 = **先生成干净视觉底图 → 再到 PS/Canva 里排正式文案**。

## 四、推荐工作流（总计约 2 小时）

| 步骤 | 时长 | 做什么 |
|---|---|---|
| 1. 分析需求 | 10 min | 明确产品、受众、卖点、比例、调性 |
| 2. 生成素材 | 30–45 min | 分别生成产品主视觉、吉祥物、装饰，至少试 3 个方向 |
| 3. 筛选修图 | 20–30 min | 检查产品结构、光影、透视、角色一致性，修瑕疵 |
| 4. 商业排版 | 30–45 min | 排版软件里完善标题、Logo、信息层级、留白 |
| 5. 作品集整理 | 20 min | 设计思路 + 初始稿 + 最终稿 + 应用效果 |

## 五、验收视角（做完后按这个标准自查）

- 构图是否像真正的商业广告（而不是"好看的图"）
- AI 生成感是否过重
- 产品是否有食欲/吸引力
- 字体和排版是否专业
- 距离求职作品集水平还差什么
