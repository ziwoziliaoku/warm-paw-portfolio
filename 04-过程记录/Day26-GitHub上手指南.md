## 〇、先用你熟悉的话说清楚：GitHub 是什么

你已经会玩 Git 了——它是**游戏的存档系统**：`commit` 是存档，`restore` 是读档。

那 GitHub 就是：

1. **云存档**：存档不只在这台电脑上，云端也有一份，电脑坏了也不丢
2. **陈列柜**：把存档摆出来给别人看，简历上可以写一个链接
3. **简历本身**：HR 点开链接，能直接看到你的代码、作品图、过程记录

所以今天做完，你手里会多一个东西：`https://github.com/你的用户名/warm-paw-portfolio`

## 二、你要做的三件事

### 第 1 步：注册 GitHub 账号（约 10 分钟）

1. 浏览器打开：https://github.com/signup
2. 填邮箱 → 设置密码 → 起一个用户名
   - 用户名建议：`拼音` 或 `拼音+数字`，比如 `jiangtian-cafe`、`warmpaw-li`
   - **用户名会出现在链接里**，别用一串乱码
3. 完成邮箱验证码（会发到你邮箱）
4. 选择免费计划（Free）即可，不需要付费

> 如果注册页打不开或卡住：换浏览器/稍后再试；国内访问 GitHub 偶尔慢，但不影响后续 push。

### 第 2 步：创建一个空仓库（约 2 分钟）

1. 登录后点右上角 **+** → **New repository**
2. 填：
   - Repository name：**`warm-paw-portfolio`**（必须一字不差，脚本按这个名字推）
   - Description：`暖爪咖啡 WARM PAW · AI 应用开发作品集（Python + 豆包大模型）`
   - 选 **Public**（公开，HR 才能免登录看到）
   - **不要**勾选 "Add a README file"、不要加 .gitignore、不要选 license
3. 点 **Create repository**
4. 你会看到一个"空仓库引导页"——**停在这里，别照着它敲命令**

### 第 3 步：双击推送（约 5 分钟）

## 三、出问题对照表（照着查，不用慌）

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| `remote: Repository not found` | 仓库名或用户名不对，或者仓库没建 | 回去检查第 2 步，仓库名必须是 `warm-paw-portfolio` |
| 弹窗一直不出现，卡住不动 | 凭据窗口被后台挡住了 | 看任务栏有没有 Git Credential Manager 窗口，点开登录 |
| `Authentication failed` | 登录被取消或密码错 | 重新双击 bat，再登录一次 |
| `fatal: not a git repository` | 不是在这个文件夹里运行的 | 确认双击的是「成果归档」文件夹里的那个 bat |
| 推送很慢/超时 | 网络到 GitHub 抖动 | 重跑一次，Git 会续传已上传的对象 |
| 中文文件名变成 `\346\210\220...` | Git 默认转义显示 | 不影响使用，我会给你设置 `core.quotepath false` |

## 四、上线之后，日常怎么更新（记住三条命令就够）

以后你改了代码或加了新作品，想让网站同步：

```bash
git add .
git commit -m "更新：加了什么"
git push
```

游戏类比：`add` = 把要存的东西放进存档筐，`commit` = 按下存档键，`push` = 上传到云端。
