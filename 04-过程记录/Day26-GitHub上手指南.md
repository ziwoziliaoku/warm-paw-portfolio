## 〇、先用你熟悉的话说清楚：GitHub 是什么

你已经会玩 Git 了——它是**游戏的存档系统**：`commit` 是存档，`restore` 是读档。

那 GitHub 就是：

1. **云存档**：存档不只在这台电脑上，云端也有一份，电脑坏了也不丢
2. **陈列柜**：把存档摆出来给别人看，简历上可以写一个链接
3. **简历本身**：HR 点开链接，能直接看到你的代码、作品图、过程记录

所以今天做完，你手里会多一个东西：`https://github.com/你的用户名/warm-paw-portfolio`

## 三、出问题对照表（照着查，不用慌）

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| `remote: Repository not found` | 仓库名或用户名不对，或者仓库没建 | 回去检查第 2 步，仓库名必须是 `warm-paw-portfolio` |
| 弹窗一直不出现，卡住不动 | 凭据窗口被后台挡住了 | 看任务栏有没有 Git Credential Manager 窗口，点开登录 |
| `Authentication failed` | 登录被取消或密码错 | 重新双击 bat，再登录一次 |
| `fatal: not a git repository` | 不是在这个文件夹里运行的 | 确认双击的是「成果归档」文件夹里的那个 bat |
| 推送很慢/超时 | 网络到 GitHub 抖动 | 重跑一次，Git 会续传已上传的对象 |
| 中文文件名变成 `\346\210\220...` | Git 默认转义显示 | 不影响使用，我会给你设置 `core.quotepath false` |

## 四、上线之后，日常怎么更新（记住三条命令就够）

以后你改了代码或加了新作品，想让网站同步：

```bash
git add .
git commit -m "更新：加了什么"
git push
```

游戏类比：`add` = 把要存的东西放进存档筐，`commit` = 按下存档键，`push` = 上传到云端。

## 六、如果 GitHub 注册页打不开（2026-11-07 追加）

**现象**：`github.com/signup` 显示「访问暂时受限」，或一直卡在人机验证。

**先别怀疑自己**：这不是账号问题，是 GitHub 对部分网络环境做了限流/风控。
实测你这台电脑访问 GitHub 的 **git 协议是通的**（能拉取公开仓库），被挡住的只是网页注册。

### 路线 A：让 GitHub 注册通过（值得先试 10 分钟）

按顺序试，通常第 1 条就有效：

1. **换网络**：手机开热点，电脑连热点后再打开 github.com/signup（最有效）
2. **无痕窗口**：Edge/Chrome 按 `Ctrl + Shift + N`，重新开注册页
3. **关掉代理 / VPN / 加速器**：开着反而更容易被判定异常
4. **换浏览器或换设备**：Edge 换 Chrome，或者直接用手机浏览器注册
5. **隔 1–2 小时再试**：这类限制是临时的，过一段时间会自己解除

### 路线 B：先用 Gitee 拿到链接（今晚就能完成，推荐）

Gitee（码云）是国内代码托管平台，HR 一样能打开，注册只要手机号。

**第 1 步 · 注册（3 分钟）**
1. 打开 https://gitee.com/register
2. 手机号 + 验证码 + 设密码 + 起用户名（会出现在链接里）

**第 2 步 · 建空仓库（2 分钟）**
1. 登录后右上角 **+** → **新建仓库**
2. 仓库名：**`warm-paw-portfolio`**（一字不差）
3. 是否开源：选 **公开**
4. **不要**勾选「使用 Readme 文件初始化这个仓库」
5. 点创建

**第 3 步 · 双击上传（3 分钟）**
1. 打开 `成果归档` 文件夹
2. 双击 **`上传到GitHub.bat`**
3. 输入 **1**（Gitee）→ 回车
4. 输入你的 Gitee 用户名 → 回车
5. 登录弹窗：用户名填 Gitee 用户名，密码填 Gitee 密码
   - 如果提示密码错误：去 Gitee「设置 → 私人令牌」生成一个，**用令牌当密码**
6. 完成后自动打开：`https://gitee.com/你的用户名/warm-paw-portfolio`

> 另有 `上传到Gitee.bat`，用法一样，只是推送到 Gitee。
> 两个 bat 都是**英文界面**（cmd 对中文路径/括号支持不稳，容易解析出错），按提示输用户名即可。
> 等 GitHub 注册通了，再双击一次选 2 即可；两个平台可以都有。
