## 二、三个可以讲清楚的项目

### 项目 1 · AI 文案 + 海报提示词工具链
`02-代码作品/09-copywriter-tool.py`（228 行，当前主力）

- **解决什么问题**：做一次新品海报，原本要手写 2 小时文案和提示词；现在输入一个产品名，30 秒产出完整方案
- **技术点**：OpenAI SDK 调用豆包大模型（火山方舟）· 函数拆分（build_prompt / call_api / save_result）· 5 套风格模板库（字典 + 兜底）· 网络失败自动重试 · 输入校验 · 结果落盘
- **产出**：海报提示词 + 三组小红书标题 + CSV/TXT 存档

### 项目 2 · 批量海报提示词生成器
`02-代码作品/08-poster-prompt-batch.py`（179 行）

- 一次输入多个产品，逐个生成提示词并汇总到 CSV
- 技术点：CSV 读写 · 循环与异常处理 · 环境变量读取密钥

### 项目 3 · 暖爪咖啡品牌视觉（视觉作品集）
`01-视觉作品/`

- 秋日海报《把秋天，装进一杯里》v1 → v2（AI 编辑修正：加投影、统一光源、收敛装饰）
- 吉祥物「小熊猫江天」三动作定稿（端咖啡 / 捧杯 / 拉花），角色一致性 8/10
- 包装延展：包装陈列、规格展示板（含尺寸标注）
- 冬日系列海报 + 包装展示板
- 说明：**不会 PS**，全部通过提示词工程 + AI 编辑完成——这本身就是一条可复用的工作流

## 三、代码怎么跑

```bash
# 1. 安装依赖（Python 3.12+）
pip install openai

# 2. 配置环境变量（不要写进代码）
#    Windows PowerShell：
setx ARK_API_KEY "你的火山方舟 API Key"
setx ARK_MODEL "你的推理接入点 ID（ep- 开头）"

# 3. 运行
python 02-代码作品/09-copywriter-tool.py
```

> 仓库内**不含任何密钥**。早期版本曾硬编码 Key，已在第 25 天全部改为环境变量读取。
